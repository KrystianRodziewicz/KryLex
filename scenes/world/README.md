# scenes/world

Właściciel: Alex.

Rzeczy w świecie, które nie są wrogami ani pomieszczeniem: kapliczka (`shrine`), Guślarz (`guslarz`), Słup Ślubów (`vow_pillar`). Każda interaktywna ma stałe tekstowe `interactable_id` do bazy świata (`shrine_1`, `vow_pillar`), zgodnie z `docs/technika.md`.

Kwestie Guślarza i ich warunki: `docs/npc-guslarz.md`. W kroku 1 M0 działa kwestia pierwszej wizyty i domyślna; warunkowe wchodzą z danymi z kroku 3.
