# scripts

Wspólne.

Klasy, które nie należą do jednej sceny: `InputFrame` (klatka wejścia, w kroku 2 M0 wysyłana do hosta), `combat/` (`Hitbox`, `Hurtbox`, `HitInfo`), `world/Interactable` (baza kapliczek, słupów, dźwigni) i `RoomCamera` (kamera trybu testowego na jednym PC).

Każdy skrypt ma `class_name` i pełne typy, bo ostrzeżenia o ich braku są w `project.godot` ustawione na błąd.
